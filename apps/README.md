# apps/

React + Vite + TypeScript frontends, hosted on Cloudflare Pages (PLAN.md sections 2.2 and 4).

| Folder | What | Built in |
|---|---|---|
| `broker/` | Broker Assistant: login, plan picker, comparison tables, CSV export | Phase 1 |
| `shopper/` | Plan Shopper: guided state and plan selection, plain-language answers | Phase 3 |
| `chat-ui/` | Shared components: chat stream, citations panel, comparison table, plan picker | Phase 1 |

The Node toolchain and its CI job are added with the first app.
